# Decision-Tree

Place the course-provided `clinic_appointments.csv` in the same folder as
`decision_tree_analysis_revised.py` and `requirements.txt`.

From that folder, run these commands on macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python decision_tree_analysis_revised.py
```

The script generates `analysis_results_revised.md` and saves the charts in
`outputs_revised/`.
